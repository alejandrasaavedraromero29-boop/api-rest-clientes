# API REST Clientes

Proyecto desarrollado con Node.js, Express y MySQL.

## Instalación

```bash
npm install
```

## Ejecutar proyecto

```bash
node server.js
```

## Tecnologías usadas

- Node.js
- Express.js
- MySQL
- Postman

## Endpoints

GET /clientes

POST /clientes

PUT /clientes/:id

DELETE /clientes/:id
